# Technical Work

## Monolith Cartographer

[View repository](https://github.com/harleybielke/Monolith-Cartographer)

A local-first mapper for PowerShell codebases. It scans large or tangled scripts, identifies function blocks, supports search and review, and can export exact source-only function blocks or a broader structural review.

The project documentation covers installation, first use, confidence and risk terminology, export behavior, testing, and explicit limits on what the tool's classifications prove.

## OpenToolTrimmer

[View repository](https://github.com/harleybielke/OpenToolTrimmer)

An experimental Python utility for finding the smallest policy-compatible reusable part of an open-source tool that the current implementation can prove.

Its documentation separates discovery, dependency completeness, reuse authority, and verification. It also documents conservative outcomes such as HOLD when required evidence or supported dependency structure is missing.

## Semantic Pressure Suite

[View repository](https://github.com/harleybielke/SemanticPressureSuite)

An auditable large language model and model-behavior evaluation harness for deterministic testing, regression analysis, preserved evidence, and reproducible judgments.

The project documents Replay and bounded LiveModel execution, result vocabulary, evidence custody, release verification, operational boundaries, and explicit non-claims.
